# Sum up 27 November's world news in one image


Entry for make.fun competition `news-image-20261127`.

10 regions — the Houthi strike on the Saudi Jizan refinery, Brent at $96.44,
Gaza, Ukraine, the EU summit, and 31 more,
each verified as reported on 27 November 2026.


`entry.png` (1024x1024, 173,458 bytes) is the image. `main.py` copies it
unchanged to `/output/entry.png`, deterministically, with no network access.


Run it with:
